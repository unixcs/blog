# 欢迎来到我的第二大脑 👋

这里是我的 [Quartz](https://quartz.jzhao.xyz) 数字花园，用来存放和发布我的笔记、想法与学习记录。

- 返回 **[个人主页](https://fengx.eu.org)** ← 右上角也有直达按钮
- 所有笔记都从本地 Obsidian 同步而来，推送到 GitHub 后自动部署到 Cloudflare Pages

> 这是示例笔记。把你的 `.md` 文件放进 `content/` 目录，推送即可发布。

## 快速开始

1. 在 `content/` 下新建 `我的笔记.md`
2. 写入 Markdown
3. 推送到 GitHub，站点会自动更新
