# 8.8 凌晨笔记复盘 — 今日接力计划

> 本笔记总结 `50_日记/2026年08月08日.md` 的凌晨段（00:52–11:18），主题是**公众号发布插件迭代 + 微信内容同步 Obsidian + 待办查看痛点（最痛：plan 乱、不知如何上手）**。
> 第一性原理：用户最痛的不是"没计划"，而是"提取出的 plan 乱、无优先级、早晨看了一头雾水"。这直接呼应 8/5 发现的「时间块回退到前天」问题——根因在提取质量与排序。
> 标注【待确认】的必须先向用户索取，禁止臆造。

## 一、凌晨日记要点总结（00:52–11:18，口述 → 要点）

### 1. 上午（8/7）已做：白嫖华为 AI 编程 CLI
- 误以为是 CSDN，实为华为相关 AI 编程对话，领一个月免费 Deepseek，下终端 CLI。
- 反代（反向代理）项目没用，直接安装更好（内置提示词走编程器反带，非账号 API 反带）。

### 2. 下午（8/7）已做 + 明日计划：公众号自动化发布插件迭代
- 已做：基于热门自动化发布集成 AI 自动润色标题、AI 生图一键生图，迭代两版，支持设置内编辑标题/生图提示词、默认风格、主题。
- **明日计划 A**：
  - A1：生成标题时提供「三个爆款标题预览」，手动点选确定。
  - A2：简介是否也生成三个（待定，先调研）。
  - A3：MP Push（二次开发的公众号插件）今天更新，增加草稿箱自动填写、同步作者等；明天拉取新代码验证不影响现有系统。
  - A4：研究能否一键自动发布到公众号以外平台（小红书、今日头条）。

### 3. 晚上（8/7）已调研：微信内容 → Obsidian 同步
- 目标：微信里公众号文章/聊天/图片快速剪切到 Obsidian（五餐厅=Obsidian 口误）成素材养料。
- 方案1：同步助手（微信服务号，手机装插件转发内容）。缺点：后期收费 300 元/年，免费版仅收公众号文章，URL/正文/图片无法摘录，需服务端清洗转录爬虫。
- 想法：自己搞**个人小程序**替代服务号（低成本）。

### 4. 最痛痛点（01:21）：待办查看 + 头脑风暴需求
- Obsidian 三端（手机/Windows/NAS）部署，NAS 里 Hermes 提取明日待办。
- 痛点：Obsidian 看每日待办麻烦，缺日历提醒/时间块显示。
- 候选：飞书日历（任务精确到小时，但重、需装 APP、不轻量）；滴答（滴答清单，可和 Obsidian 打通输出待办，但 CLI/插件/每小时精度未知）。
- **用户原话最痛**：「提取出来的 plan 很乱，每天早晨看这乱七八糟的 plan，不知道如何上手」。
- 明确要求：Hermes 从第一性原理头脑风暴待办查看方案。

## 二、第一性原理：乱的根因与解法

| 层    | 真相                                            |
| ---- | --------------------------------------------- |
| 痛点本质 | 不是没计划，是提取的 plan 无序、无优先级、可能滞后（8/5 已证：时间块回退到前天） |
| 解法方向 | 提取时即结构化 + 按重要程度排序 + 透明标注来源日期（缺失则告警）           |
| 轻量优先 | 飞书重→优先验证滴答/轻量方案；不强上重工具                        |
| 内容养料 | 微信→Obsidian 需低成本（个人小程序优于 300/年服务号）            |
