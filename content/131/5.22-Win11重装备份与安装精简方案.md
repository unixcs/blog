# Win11重装备份与安装精简方案

## 时间

- 日期：2026-05-22
- 场景：为即将重装 Windows 11 做重装前备份梳理、镜像选择、安装后精简方案规划。

## 用户目标

- 重装 Win11 后，避免 C 盘重要配置、账号环境、软件数据丢失。
- 重点保住并可快速恢复：`WSL2`、`OpenCode`、`Claude`、`OneDrive`、`OneNote`、浏览器数据、Obsidian、常用工具。
- 当前机器有个人版和非个人版 OneDrive 路径，要求统一纳入备份规划。
- 希望系统装完后做轻量化精简，删除游戏、广告、小组件、预装 App、推荐内容，但不能影响 `WSL2`、`Edge`、`OneDrive`、`OneNote`、开发工具和 AI 工具。
- 最终希望把备份实际落到 `D:\back`，但本轮先完成方案确认，不直接执行备份。

## 背景与上下文

- 用户准备重装 Win11，C 盘会丢失，需要先梳理配置环境和数据文件备份范围。
- 用户重装系统的一个核心原因是后续要继续安装/修复 `WSL2`；当前 WSL 文件落在 `D:` 盘，但重装后仍可能因系统注册关系丢失而无法直接使用。  
- 用户常用：`Edge`、`WSL2`、`OneDrive`、`OneNote`、`OpenCode`、`Claude`、`Obsidian`、`Listary`、`yV2ray`、`Clash`、`LazyTyper`、`AI Toolbox`、`MobaXterm_Portable_v24.3_chs`、`tailscale-ipn` 等。
- 用户提供的 OneDrive 路径：
  - 个人版：`C:\Users\fengx\onedrive\`
  - 非个人版：`E:\资料\备份\OneDriver\`
- 用户还关心当前开始菜单布局、浏览器数据备份、以及重装后要“无缝迁移”。

## 过程摘要

### 1. 初步盘点与关键路径核对

- 先建立了本轮待办：盘点需备份范围、检查 WSL/OpenCode/Claude/OneDrive/常用软件位置、整理恢复顺序与精简建议。
- 核对到以下关键目录实际存在：
  - `C:\Users\fengx\.config`
  - `C:\Users\fengx\.ssh`
  - `C:\Users\fengx\.gitconfig`
  - `C:\Users\fengx\OneDrive`
  - `C:\Program Files\LazyTyper`
  - `C:\Program Files\Tailscale`
  - `C:\Program Files\Listary`
  - `E:\资料\备份\OneDriver`

### 2. WSL 现状核对

- `wsl --status` / `wsl -l -v` 返回表现异常，未正常列出发行版。
- 在 `D:` 盘发现 `D:\WSL`，其下有：
  - `D:\WSL\backups`
  - `D:\WSL\temp`
  - `D:\WSL\Ubuntu-24.04`
  - `D:\WSL\Ubuntu-24.04\ubuntu-24.04.4-wsl-amd64.wsl`
- 结论：WSL 文件确实有落在 `D:` 盘，但系统识别关系并不可靠。即使 D 盘文件保住，重装后仍应通过重新启用 WSL 功能、重新导入发行版的方式恢复。强烈建议额外做 `wsl --export` 导出备份。

### 3. OpenCode / Claude 现状核对

- OpenCode 配置目录存在：`C:\Users\fengx\.config\opencode`
- Claude 本地数据目录存在：`C:\Users\fengx\.claude`
- `where.exe opencode` 命中：`C:\Users\fengx\scoop\shims\opencode.exe`
- `C:\Users\fengx\scoop\apps\opencode\current` 也存在，说明 CLI 侧是 Scoop 安装。
- 同时开始菜单 `OpenCode.lnk` 指向 `D:\Program\soft\...\OpenCode\OpenCode.exe`，说明机器上还存在一套 D 盘 GUI/安装版 OpenCode。
- Claude 可执行位置为：`C:\Users\fengx\.local\bin\claude.exe`
- 结论：
  - `OpenCode` 不能只备份配置，后续恢复时还要恢复其安装方式（至少包含 Scoop CLI 这套）。
  - `Claude` 同理，除了可执行环境，还必须保住 `C:\Users\fengx\.claude`。

### 4. 浏览器与笔记数据核对

- 浏览器用户数据目录已确认：
  - Edge：`C:\Users\fengx\AppData\Local\Microsoft\Edge\User Data`
  - Chrome：`C:\Users\fengx\AppData\Local\Google\Chrome\User Data`
  - 豆包：`C:\Users\fengx\AppData\Local\Doubao\User Data`
- Obsidian 配置目录存在：`C:\Users\fengx\AppData\Roaming\obsidian`
- 读取 `C:\Users\fengx\AppData\Roaming\obsidian\obsidian.json` 后确认主 vault：
  - `C:\Users\fengx\onedrive\Apps\remotely-save\feng`
- 另发现第二套 vault 痕迹：
  - `C:\Users\fengx\onedrive\obsidian\Feng`
- 结论：Obsidian 必须同时备份程序配置和 vault 本体，不能只保 `AppData\Roaming\obsidian`。

### 5. 常用软件配置与路径核对

- 已确认配置/数据路径：
  - Listary：`C:\Users\fengx\AppData\Roaming\Listary`
  - Tailscale：`C:\Users\fengx\AppData\Local\Tailscale`
  - Clash：`C:\Users\fengx\.config\clash`
- 通过注册表与目录搜索定位到部分软件本体在 D 盘：
  - `AI Toolbox`：`D:\Program\soft\...\AI Toolbox`
  - `Clash Verge`：`D:\Program\soft\...\Clash Verge`
  - `Clash.for.Windows`：`D:\Program\soft\...\Clash.for.Windows-0.20.24-win`
  - `MobaXterm_Portable_v24.3_chs`：`D:\back\MobaXterm_Portable_v24.3_chs` 及 `D:\Program\soft\实用工具\远程终端\MobaXterm_Portable_v24.3_chs`
  - `Doubao`：`D:\Program\soft\...\Doubao`
  - `LazyTyper`：D 盘目录有痕迹，同时系统注册表里安装目录为 `C:\Program Files\LazyTyper`
  - `360Chrome`：`D:\Program\soft\...\360\360Chrome`
  - `QuarkCloudDrive`：`D:\ProgramData\QuarkCloudDrive`
  - `Typora`：`D:\学习\工具\Markdown工具\Typora`
  - `PotPlayer`：`D:\Program\soft\...\PotPlayer`
- 结论：不少程序本体在 D 盘，但注册表、自启动、PATH、用户配置很多仍在 C 盘，重装后不要假设程序目录还在就能直接用。

### 6. 软件清单与开始菜单/自启动线索

- 通过注册表和开始菜单目录提取到了大量已安装软件线索，便于重装后找回：包括 `OpenCode`、`Claude`、`VS Code`、`Cursor`、`Chrome`、`Edge`、`Obsidian`、`OneDrive`、`OneNote`、`Tailscale`、`Listary`、`LazyTyper`、`AI Toolbox`、`Clash Verge`、`MobaXterm`、`PotPlayer`、`Typora`、`QuarkCloudDrive` 等。
- 开始菜单布局相关文件确认：
  - `C:\Users\fengx\AppData\Local\Packages\Microsoft.Windows.StartMenuExperienceHost_cw5n1h2txyewy\LocalState\start2.bin`
  - `C:\Users\fengx\AppData\Local\Microsoft\Windows\Shell\DefaultLayouts.xml`
- 开始菜单快捷方式目录与 Startup 目录已枚举，用于后续恢复固定项与自启动：
  - `C:\Users\fengx\AppData\Roaming\Microsoft\Windows\Start Menu\Programs`
  - `C:\ProgramData\Microsoft\Windows\Start Menu\Programs`
  - `C:\Users\fengx\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup`
  - `C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup`

### 7. 备份目录结构与执行策略规划

- 规划将未来备份落到：`D:\back\win11-reinstall-backup-20260522\`
- 建议拆成以下分组：
  - `01_Core-Identity-And-AI`
  - `02_Browsers`
  - `03_Notes-And-Cloud`
  - `04_WSL-And-Dev`
  - `05_App-Configs`
  - `06_Portable-And-Disk-Apps`
  - `07_System-Layout-And-Inventory`
- 执行原则：
  - 只做复制备份，不移动、不删除源数据。
  - 优先保住 `OpenCode`、`Claude`、`SSH/Git`、`WSL`、浏览器、Obsidian、OneDrive、Clash/Listary/Tailscale。
  - 大体量 OneDrive 不建议盲目全量复制，可先按重点目录处理。
  - WSL 导出应单独处理，不建议和普通目录复制混在一起。

### 8. Windows 11 镜像与版本选择讨论

- 明确不推荐优先用第三方精简版作为主力重装底座，原因是会给 `WSL2`、`Store`、`WebView2`、`OneDrive`、`Edge`、AI 工具、开发工具恢复埋坑。
- 对比过 `Windows X-Lite11 V3`、`Tiny11`、`不忘初心 LTSC 2024`：
  - 若非要三选一，排序为：`Windows X-Lite11 V3 > Tiny11 > 不忘初心 LTSC 2024`
  - 但整体仍建议：**微软官方原版 Win11 + 安装后手动轻量化**。
- 用户后续展示了多个原版镜像项，给出的建议是：
  - 选 `x64`
  - 优先 `consumer editions`
  - 年份/版本优先 `25H2`
  - 安装时优先选 `Windows 11 Pro`
- 用户指出 `business editions` 里也有专业版；对话中给出的答复仍是：对于当前个人重装场景，`consumer editions` 更顺手，避免企业版/教育版/批量授权岔路。

### 9. 安装后精简方案规划

- 给出原则：保留 `Store`、`Edge`、`WebView2`、`OneDrive`、`WSL`、`Virtual Machine Platform`、`Hyper-V`（按需）、`Windows Terminal`、`Defender` 基础能力、`.NET`、`Windows Update`。
- 建议清理：
  - Xbox / 游戏类
  - 广告、推荐、提示
  - Widgets 小组件、新闻资讯
  - 无用预装 App
  - 多余自启动与后台项
- 精简分组：
  - A 组：关广告/推荐/烦人提示
  - B 组：关小组件/资讯/消费者内容
  - C 组：删除不用的预装 App
  - D 组：清理自启动和后台常驻
  - E 组：隐私与后台权限瘦身
  - F 组：功能组件白名单保护
- 核心思想：这是“稳妥型轻量化”，不是极限魔改，不破坏后续恢复 `WSL2`、`OneDrive`、`OpenCode`、`Claude`、浏览器/Obsidian 的前提。

### 10. 重装后第一小时操作顺序表

- 生成了一版“Win11 重装后第一小时操作顺序表”，重点包括：
  - 启动 U 盘进入安装程序
  - 分区阶段只动 C 盘系统分区，明确不要碰 D/E 数据盘
  - 版本优先选 `Windows 11 Pro`
  - 首次进桌面先联网、登录 Microsoft 账号、观察初始化
  - 第一小时内优先确认：`Edge`、`Microsoft Store`、`OneDrive`、`Windows Update` 是否正常
  - 第一小时不要急着恢复 `OpenCode`、`Claude`、浏
