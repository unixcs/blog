## 一、凌晨日记要点总结（01:32–01:50，口水话 → 要点）

### 1. 公众号推文自动化（01:32–01:46）
- **插件对比**：OC 插件三个——能排版不能推送 / 能推送但收费 / 最终免费版自带推送。
- **踩坑**：排版 secure 本地生成 HTML 推公众号，比例缩放难受；预览版复制粘贴不进（网络/Edge 原因），放弃手动传。
- **落地方案**：Obsidian 开源插件（排版+自动推送），配公众号 AppID + secret，后台允许 `0.0.0.0/0` → 直接推送。
- **两种内容生产**：
  - 方案1：语音输入/瞬间灵感 → 口述 AI 润色查资料 → 成文。
  - 方案2：热文/AI 晨报汇总 → 生成 MD → 加「人味 skill」去 AI 味 → 定稿。
- **自动化阶段**：纯文字稿可全服务器跑（绕过图片）→ 接 HiMOS（Hermes），对话框发主题自动调研/生成/排版/推送草稿箱；或 Telegram 发素材稿 → HiMOS 提取 → 口述点 → 重生成 → 自动推文。
- **图片方案**：手机麻烦（图床 URL/实名）；电脑慢工出细活（教程类，预留图位 + 阿里云图床 → 最终版 → Hermes/codebox 推送）。
- **多平台**：文章同步知乎/小红书/推特。

### 2. AI 视频拓展（01:46）
- 形式：PPT 或 APT喵方案；第一版视频发抖音。
- 粗剪：开源剪映 OpenUP + 录屏素材 + 真人出镜口播（后期）。
- 节奏：先短视频（抖音/B站）→ 长视频（B站/YouTube）。

### 3. 真人沟通 / 身体（01:50）
- 今天少说话，真人沟通难受（"嗓子卡东西，不知如何说"）；需调动身体肌肉力量才有气、说话饱满。
- 饿得受不了（5 点多吃没饱、回来忘吃）；"需要增肥不是减肥，营养身体健康"。

### 4. 中介 / 二房东事务（01:50，已完成）
- 昨晚 11:30 中介电话客户约今上午；第一性原理→直接打电话给二房东（已办）。
