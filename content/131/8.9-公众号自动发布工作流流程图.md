                           ▼
  ┌──────────────────────────────────────────────┐

                           ▼
        ┌─────────────── 分支选择 ───────────────┐
        │                                        │

  ┌─────────────────────────────┐   ┌─────────────────────────────┐

  │    只能建草稿，群发须人工点击                 │
  └──────────────────────────────────────────────┘

──────────────────────────────────────────────────────────────
  五条铁律
──────────────────────────────────────────────────────────────
  1. 单推送出口    微信副作用仅经 peterpan（禁用 md2wechat --upload/--draft）
  2. 排版合规门    交付 HTML 必须 validate 0 ERROR，不得跳过
  3. 封面必填      无封面禁止建草稿，先 upload-cover 取 media_id
  4. 去AI味必做    正式发文前必须 humanize（路线二除外）
  5. 初稿先确认    任何推送前，初稿先经用户确认/授权

──────────────────────────────────────────────────────────────
  错误码速查
──────────────────────────────────────────────────────────────
  40001  token 无效/不是最新   删 token.json 后重试
  40014  token 过期             同上，重新 auth
  40164  出口 IP 不在白名单    勿重试，后台加白名单
  40013  参数错误（缺封面）     补 --thumb 再试
  42001  token 刷新过频         等 1 分钟
  48001  个人号无 freepublish  属正常，建草稿+人工群发
  45009  API 调用超限           等配额恢复
