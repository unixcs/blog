# 腾讯云环境快速上手（Tencent Quick Start）

> 更新: 2026-08-31 ｜ 面向: 在这台服务器上开 AI 会话的用户与 AI 本身
> 一句话: **这台机器是整个私网 AI 基础设施的"主控"——MindFS 统一入口在这里，从这里用 AI 驾驭其余 9 台设备。**

---

## 1. 这台机器是什么（30 秒版）

| 角色    | 说明                                                   |
| ----- | ---------------------------------------------------- |
| AI 主控 | MindFS（手机/电脑统一入口）+ Codex/OpenCode/pi/CodeBuddy 多 CLI |
| 生产    | **yoshop 微信电商**（wx.gxwqb.cn）——碰坏它你心疼，红线见 §6          |
| 私网枢纽  | Tailscale + 自建 DERP 中继（txcn），其余 9 台设备都从这里私网可达        |
| 运维跳板  | /opt/vps/ 存有全部服务器资料副本，AI 从这里 SSH 到任何一台               |

## 2. 目录地图（本机关键路径）

| 路径 | 是什么 | 谁用 |
|---|---|---|
| **/opt/vps/** | 服务器地图 ROUTING.md + 10 台设备 AGENT.md 副本（零公网 IP） | **AI 会话第一步读这里** |
| /opt/mindfs-data/ | AI 配置单一事实源（.codex/.pi/.config/opencode）+ AI 专用私钥 | mindfs 用户 |
| /mnt/0/ | MindFS 面板工作区（本文件所在处，面板文件树可见） | AI 会话工作目录 |
| /opt/data/ | hermes 等既有服务数据（勿动） | 旧服务 |
| /srv/yoshop/ | 电商生产代码（红线区） | 仅发布流程 |
| /opt/vps-original 不在本机 | 公网恢复资料在 WSL 的 /opt/vps-original/（本机只有零公网 IP 副本） | 故障恢复 |

## 3. 用户三步上手（手机 / 电脑）

1. **打开 MindFS**：手机/外网 → `https://tx-tencent.taile8eadf.ts.net:8443`（需 Tailscale 在网）；本机 → `http://127.0.0.1:7331`
2. **新开会话**（默认 pi），第一句话说：
   > 先读 /opt/vps/ROUTING.md，然后按地图去 XX 服务器做 XX
3. **看结果**：会话通知会推送；文件树里 /mnt/0/vps/ 随时可查资料

## 4. AI 接手三步（每个新会话照此执行）

```text
① 读 /opt/vps/ROUTING.md          → 找到目标服务器（唯一地图，零公网 IP）
② 读 /opt/vps/<目标机>/AGENT.md   → 该机的约束、服务、注意事项
③ 私网 SSH 连接执行               → 私钥在 /opt/mindfs-data/.ssh/id_ed25519_aiops
```

- 连接方式 = ROUTING.md 表内"私网连接方式"列（如 `ssh root@`tailnet内网IP（已脱敏）` -p 2255`）
- **默认禁止公网连接**；公网信息在 WSL `/opt/vps-original/`，仅私网整体故障时人工使用
- 详细配置/红线/凭据方式 = `/opt/vps/` 副本没有的部分，查 WSL 侧 `docs/server-inventory.yaml`

## 5. 身份与权限

| 身份 | 用途 |
|---|---|
| `mindfs` 用户 | MindFS 与 AI 会话的运行身份（**绝不 root 跑 MindFS**） |
| `aiops-mindfs` 私钥 | AI 跳转各服务器的钥匙（位置见 §4；WSL 侧另有一把 aiops-wsl，可独立撤销） |
| `codexrun@` + /usr/local/sbin/codex-run.sh | 受限远程执行通道（Windows 同步用） |
| `deployer` | 仅能跑 yoshop-release 发布 |

## 6. 红线（违反=事故）

- **生产禁止清单**（不得停止/删除/重启）：nginx、mysql、php8.3-fpm、redis、yoshop2.0-timer、yoshop-backup、sing-box、tailscaled、fail2ban、ssh、docker、cron、tat_agent；hermes-gateway/omniroute 仅可 restart
- B 环 wx.gxwqb.cn 是生产；A 环 wx.oiob.cn 只用于 WSL 测试，配置不得互换
- 不新增公网端口；数据库/Redis 只听 loopback
- 改 AI 配置后需**新开会话**才生效（已开会话不热加载）

## 7. 常用命令速查

```bash
# 本机常用
tailscale status                     # 私网状态
systemctl status mindfs              # MindFS 服务
curl -sk -o /dev/null -w '%{http_code}\n' https://tx-tencent.taile8eadf.ts.net:8443   # MindFS 入口(应 200)

# 到目标机（示例：yun1 测试机）
ssh root@`tailnet内网IP（已脱敏）` 'hostname'

# 全网 14 项验收矩阵 / 资料副本同步 —— 脚本在 WSL（Remote AI Coding/ops/）：
#   bash ops/acceptance-sweep.sh    （WSL+tx 双通道矩阵/P5/流水线/服务完好）
#   bash ops/sync-routing.sh        （WSL → 本机 /opt/vps/ 副本同步）
# 本机 AI 会话需要全网体检时：让 WSL 侧 AI 跑，或逐台 ssh 探测
```

## 8. 故障恢复

- 私网某台不通 → 先看 ROUTING.md 状态列 → 仍不通 → **人工**取 WSL `/opt/vps-original/` 的公网信息（AI 默认禁公网）
- 本机失联兜底：腾讯云控制台 VNC（公网 22 红线保留就是为这个）
- MindFS 挂了不影响 SSH 生命线：`tailscale → ssh → tmux → CLI` 永远在
