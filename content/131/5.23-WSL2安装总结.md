## 二、重装后 WSL2 安装过程

### 第 1 阶段：排查 WSL2 无法启动
- 初始状态：WSL2 无法运行，提示 BIOS 虚拟化问题
- 排查发现：重装后 BIOS 虚拟化设置需要确认

### 第 2 阶段：启用 WSL2 运行层
执行命令：
```powershell
wsl --update
wsl --install --no-distribution
wsl --set-default-version 2
```
结果：WSL2 底座成功启动

### 第 3 阶段：安装 Ubuntu 24.04
```powershell
wsl --install -d Ubuntu-24.04
```
结果：从微软在线下载并安装成功，状态 `Running`，版本 `2`

### 第 4 阶段：迁移 WSL 到 D 盘
原因：默认装在 C 盘，用户需要放 D 盘

步骤：
```powershell
# 1. 导出
wsl --export Ubuntu-24.04 D:\WSL-Backup\Ubuntu-24.04-export.tar

# 2. 注销
wsl --unregister Ubuntu-24.04

# 3. 导入到 D 盘
wsl --import Ubuntu-24.04 D:\WSL\Ubuntu-24.04 D:\WSL-Backup\Ubuntu-24.04-export.tar
```

结果：
- C 盘 WSL 目录已清理
- ext4.vhdx 移至 `D:\WSL\Ubuntu-24.04\`（1.39GB）
- 临时备份已删除

### 第 5 阶段：修复 Windows Terminal
- 安装了 Ubuntu Mono 字体（winget）
- Terminal 配置中 Ubuntu-24.04 字体改为 `JetBrainsMono Nerd Font`
- 删除了重复的旧版 Ubuntu 配置
