# 9.5 Ainovel番茄发布助手断连修复

- 时间：2026-09-05（Edge 插件显示"本地助手未连接 / HTTP 401"）
- 原因：
  1. 本地服务未运行，且 8787 端口被本机另一 nginx 服务（Basic realm "DeepSeek Harness (LAN)"）占用，健康检查打到它返回 401（HTML，非助手 JSON）。
  2. 版本错位：插件 0.3.9，本地安装的 companion 仍是 0.3.6（源码已是 0.3.9，venv 未重装），对上也会报 409。
- 处理（均已完成，无需重做）：
  - `%LOCALAPPDATA%\AinovelPublisher\config.json` 的 `api.port` 改为 8788；服务已在 `http://127.0.0.1:8788` 以 0.3.9 运行（书《尘尽天开》335 章 / 待发布 267 / 冲突 1）。
  - `extension/manifest.json` 放行 8788；`background.js` 默认地址改为 8788。
  - venv 重装为 0.3.9；根目录 `ainovel-publisher.exe` 用 PyInstaller 从当前源码重建并验证为 0.3.9。
  - `README-先看这里.txt` 已更新为新端口与浏览器侧步骤。
- 用户侧待做：`edge://extensions` 点"重新加载" → 侧栏接口改为 `http://127.0.0.1:8788` + 粘贴 `查看本地Token.cmd` 的 Token → "保存并测试"见蓝色"已连接" → 点"检查并处理下一章"。
- 注意：服务已在运行，不要再双击"启动助手.cmd"；仅重启电脑后双击一次。Token 值见"查看本地Token.cmd"实时输出（此处不记录）。

归属判断：Ainovel 发布助手在 `100_Wiki/INDEX.md` 项目清单中无匹配项目（仅有"知识沉淀/公众号"），且 durable 事实已记在项目仓库 `README-先看这里.txt`（source of truth），按 skill 规则不新建目录、不写 100_Wiki，仅此归档。如需长期跟踪该项目，请手动新建项目目录后再沉淀。
