# 8.14 搜索OpenWrt兆能M2固件项目总结

> 搜索并找回几年前 star 过的 OpenWrt 兆能 M2 (ZN-M2) 固件项目。

## 背景

用户几年前 star 过一个为 **兆能 M2 (ZN-M2)** 路由器编译的 OpenWrt 固件项目，但后来项目被作者删除，希望在 GitHub 上找回该项目的信息。

## 硬件信息

- **机型**：ZN M2（板号 zn,m2）
- **CPU**：Qualcomm IPQ60xx 系列 (IPQ6018)，ARM Cortex-A53，4 核，aarch64_cortex-a53
- **内存**：约 970 MB (1GB)
- **架构**：ipq60xx/generic

## 系统信息

- **系统**：OpenWrt 19.07-SNAPSHOT（基于 Lean LEDE 魔改）
- **版本号**：R23.5.1（Lean LEDE 特有的 R+日期版本号）
- **内核**：Linux 4.4.60（编译于 2023-07-25）
- **预装插件**：
  - luci-app-openclash
  - luci-app-ssr-plus
  - luci-app-turboacc
  - luci-app-cpufreq
  - luci-app-zerotier
  - 主题：luci-theme-design + bootstrap
- **软件源**：mirrors.pku.edu.cn/immortalwrt/...

```bash
comm -12 <(gh api user/starred --paginate --jq -r '.[].full_name' | sort) \
```

## 结论

**该项目极大概率就是 `sdf8057/ipq6000`，但已被作者删除。**

证据：
1. 用户描述的特征（ZN-M2、IPQ6000、内核 4.4.60、Lean LEDE 魔改）与 `sdf8057/ipq6000` 完全吻合
2. `lazyoop/ipq6000` 的描述明确写着 "sdf8057 ipq6000 openwrt"
3. 项目被删除后，star 记录不会保留在用户的 starred 列表中
